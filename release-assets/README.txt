CÓMO JUGAR
----------
1. Extrae TODA esta carpeta en un sitio con permiso de escritura:
   Escritorio, Descargas, Documentos...  NO la pongas dentro de
   "Archivos de programa" / "Program Files" (el actualizador no
   podría escribir ahí).

2. Ejecuta   Launcher.exe
   - Comprueba si hay una versión nueva.
   - Si la hay, la descarga y la instala (con barra de progreso).
   - Luego abre el juego.
   - Sin internet: pulsa "Jugar" para usar la versión instalada.

3. Si prefieres saltarte la comprobación, abre   Game.exe   directamente.


PARTIDAS GUARDADAS
------------------
Se guardan FUERA de esta carpeta, en:

   C:\Users\<TU_USUARIO>\AppData\Roaming\Pokemon Ultra Yea

Por eso actualizar el juego NUNCA borra tu partida. Si quieres una
copia de seguridad, copia esa carpeta.

(Se pueden reasignar desde el menú F1.)


PROBLEMAS FRECUENTES
--------------------
- "Windows protegió tu PC" (SmartScreen):
  pulsa "Más información" -> "Ejecutar de todas formas".
  Es normal en programas sin firma digital.

- El antivirus bloquea Launcher.exe o Game.exe:
  márcalos como excepción. Es un falso positivo habitual en
  ejecutables de fangames y en programas .NET autocontenidos.

- El juego no arranca / se cierra solo:
  abre  launcher.log  (junto a Launcher.exe) y, si existe, el
  archivo de error de mkxp, y adjúntalos al reportar el fallo.
